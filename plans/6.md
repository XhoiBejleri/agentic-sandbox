# Plan for #6: Add PATCH /api/runs/:id/status with allowed transitions

## Goal
Allow clients to advance a measurement run from `planned` to `running`, then from `running` to `done`. Keep the existing run endpoints and initial `planned` status unchanged.

## Dependencies
- **confirmed** — change: yes — `src/runs.ts` (`RunStatus`, `MeasurementRun`, `RunStore`) owns status values and in-memory run state; add transition behavior here.
- **confirmed** — change: yes — `src/app.ts` (`createApp`) owns API routes and not-found/error response conventions; add the PATCH endpoint.
- **confirmed** — change: yes — `test/app.test.ts` tests endpoints through `createApp` with supertest; cover allowed transition(s), invalid transition response, and unknown ID.
- **confirmed** — change: yes — `README.md` API table documents routes; add the PATCH response and error contract.
- **confirmed** — change: no — `src/config.ts`, `k8s/configmap.yaml`; the endpoint introduces no environment configuration.
- **plausible** — change: no — `public/index.html`, `e2e/`; ticket requests a JSON API and unit tests, not a page workflow.

## Tests
- `test/app.test.ts`: planned-to-running and running-to-done success; disallowed planned-to-done returns 409 with `error`, `from`, and `to`; unknown ID returns 404.
- Also verify malformed/missing status uses the existing 400 validation contract.

## Environment contract
No new variables. Existing config contract stays unchanged.

## Risks
- Incorrectly accepting skipped or repeated transitions could leave the lifecycle inconsistent; enforce transitions in domain logic and cover rejection.
- Error shape must retain both current and requested status on 409.
- CI unit/build and ephemeral-cluster deploy/smoke/browser jobs may fail if endpoint or response behavior regresses; no Kubernetes changes are planned.

## Open questions
None. Assumption: a well-formed string target outside the allowed transition is a 409 invalid transition; missing or non-string status is malformed input (400).

## Decisions
- No user decisions needed; proceed with the assumption above.
